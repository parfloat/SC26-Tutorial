SC26 Nixnan Tutorial: Floating-Point Precision Limits in Reaction-Diffusion CUDA

Format Legend:
FP16: 5-bit exp, 10-bit mantissa (fails earliest) BF16: 8-bit exp, 8-bit mantissa (range okay, precision compromised) FP32: 8-bit exp, 24-bit mantissa (reference precision)

1. Overflow Timeline

What: Step count at which each format first overflows to infinity (solid bar), or how far it got without overflowing (hatched bar).

Key finding: At M=1600 steps, only FP16 overflows (step 300). BF16 and FP32 keep growing but stay finite — this build was deliberately shortened from M=2500 specifically so higher precisions survive the run (see nixnan git history: "Reduce rd_nixnan.cu to M=1600 steps to avoid overflow in higher precisions").

Physics: Reaction term grows ~1.05× per step; FP16's narrow exponent range (5 bits) saturates first, long before BF16/FP32's 8-bit exponent range would.

2. Exception Propagation

What: Per-format count of NaN and Infinity exceptions (log scale), from traces-new/Stage3/exceptions_summary.txt.

Key finding: FP16 shows 60,556 total NaN occurrences (22 unique sites) and 661 Infinity occurrences (22 unique sites) — a cascade from the overflow at step 300 propagating for the remaining 1300 steps. BF16/FP32 show zero exceptions: they never leave the finite range within this run.

Teaching moment: Infinity triggers NaN in the next iteration (inf − 2·inf + inf = NaN); the 1300 remaining steps after FP16's overflow is what turns 22 unique sites into 60K+ total occurrences.

3. Dynamic Range

What: Exponent range actually reached by each format through step 1600, from traces-new/Stage4/histogram_full.txt.

FP16: Fixed capacity [-14, 15] (29 total exponent values); exceeds it at step 300 and reports inf.

BF16 & FP32: Both reach unbiased exponent 113 by step 1600 — identical trajectory, since they follow the same double-precision-equivalent growth curve; both still have headroom to their shared ceiling of 127.

4. Per-Instruction Error Hotspots

Hottest instructions by format (from traces-new/Stage3):

  • FP16: HFMA2 (24 flagged occurrences), HADD2 (9 flagged occurrences) — packed FP16 ops carrying NaN/Inf propagation through the stencil.
  • BF16: no hotspots — zero exceptions occurred within 1600 steps.
  • FP32: no hotspots — zero exceptions occurred within 1600 steps.

Stencil anatomy: Laplacian (u_{i+1} - 2u_i + u_{i-1}) is where the Infinity first appears (HADD2/HFMA2); the reaction term's own FMA (HFMA2) then spreads the corruption every step after.

5. Mantissa Precision Impact

Left: Mantissa width — BF16's 8 bits vs FP32's 24 bits. (Format-defined; unchanged by M.)

Right: Diffusion term fidelity in PDE. BF16 (~2⁻⁸·u) is below noise floor → physics lost, independent of whether/when overflow happens.

Hook: BF16 and FP32 share the same exponent range and (per card 3) the same trajectory through step 1600, yet BF16's diffusion signal is already gone — precision loss that no exception counter catches.

Interpretation Guide

  • Why this differs from the archived viz/: The original visuals were built against an M=2500 run where BF16/FP32 also eventually overflow (~step 1900). The rd_nixnan.cu that produced traces-new/ is the last version that ever existed in nixnan's git history, which deliberately shortened the run to M=1600 specifically so higher precisions survive — a different, and arguably cleaner, teaching point (precision-dependent failure vs. universal-eventual-failure).
  • FP16 subnormals: Zero in this run (high growth rate λ=50, matching the original design note). Lower λ or raise dt to push boundary diffusion below 2⁻¹⁴ and observe subnormal underflow instead of overflow.
  • BF16 vs FP32 parity: Identical exponent trajectory (both reach 113 by step 1600, card 3), but BF16's 8-bit mantissa already renders the diffusion term invisible (card 5) — precision loss that isn't flagged by any exception counter, because nothing overflows.
  • max_element() silent failure: After NaN propagates through FP16's interior, all comparisons with NaN return false → reports 0.0 (boundary), not inf/NaN. Classic silent failure mode, visible in traces-new/Stage2.
  • Exception timeline: FP16 hits Infinity at step 300; NaN follows on the very next stencil iteration via inf − 2·inf + inf. The other 1300 steps of the run is pure cascade — 22 unique sites become 60K+ total occurrences.
