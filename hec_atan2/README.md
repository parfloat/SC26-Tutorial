# hec_atan2

A local copy of HeCBench's `atan2-cuda` benchmark, kept here as this
tutorial's own scratch/test area for quick, small-scale runs -- separate
from the `external/HeCBench` submodule, which tracks upstream and isn't
something we can push changes to (see "Provenance" below).

## What this benchmark does

Evaluates several fixed-degree polynomial approximations of `atan2(y, x)`
(coefficients generated by [Sollya](https://www.sollya.org/) scripts, see
the comment block at the top of `main.cu`) against `std::atan2`, across
three output representations -- `f32` (the float result directly), `i32`,
and `i16` (the result quantized to fixed-point integers) -- reporting
average kernel execution time and RMSE against the reference for each.
Command line: `./main <number of coordinates> <repeat>`.

## Files

- `main.cu`, `Makefile`, `CMakeLists.txt`, `LICENSE` -- copied verbatim
  from upstream (see Provenance), unmodified.
- `MakeShort` -- **new here, not upstream.** Identical to `Makefile`
  except its `run` target uses 8 coordinates, repeated once
  (`./main 8 1`), instead of upstream's 10,000,000 coordinates repeated
  100 times (`./main 10000000 100`). A quick smoke test, not a benchmark
  measurement -- use `make -f MakeShort run`.
